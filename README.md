# Power-Bi-Dashboard

SuperStore Sales Dashboard 📊

An interactive Power BI dashboard designed to track, analyze, and optimize retail sales performance. This dashboard transforms transactional data into actionable insights covering profitability, operational efficiency, and regional performance trends

The goal of this project is to transform sales data into meaningful visual insights that support data-driven business decisions

Key Performance Indicators (KPIs)

  Total Sales: Approximately 0.45M
  Total Profit: Approximately 59K
  Total Orders: Approximately 6K
  Average Shipping Days: 103, as displayed in the dashboard
Note: KPI values reflect the dashboard screenshot and may change with different filters or data.

Dashboard Features
Sales by Payment Mode: Analyze sales distribution across payment methods.
Sales by Region: Compare performance across geographical regions.
Sales by Segment: Understand sales contribution from different customer segments.
Sales by Month: Track monthly sales trends.
Profit by Month: Monitor monthly profitability.
Sales by Ship Mode: Compare shipping methods.
Sales by Category: Evaluate Furniture, Office Supplies, and Technology.
Sales by Subcategory: Identify important product subcategories, including Phones, Chairs, and Machines.
Sales by State: Explore geographical sales distribution.
Interactive Filters: Filter the dashboard by region.

Key Insights
  The dashboard provides a consolidated view of sales, profit, and order performance.
  Monthly sales and profit charts help identify trends and fluctuations.
  Category and subcategory visuals help compare product performance.
  Regional and state-level visuals support geographical analysis.
  Shipping and payment-mode charts help analyze operational sales patterns.

Tools & Technologies
  Microsoft Power BI Desktop
  Power Query for data transformation
  DAX for measures and calculations, where applicable
  Data visualization and interactive reporting
  SuperStore sales dataset
